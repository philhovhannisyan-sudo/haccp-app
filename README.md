# haccp-app

Веб-приложение HACCP-прослеживаемости варенья и джемов: приёмка сырья → производство → реализация, прослеживание по коду с банки и по лоту сырья.

Открыть: https://philhovhannisyan-sudo.github.io/haccp-app/

Здесь только код приложения. Данные хранятся в приватном репозитории `Claude-projects` (`data/haccp.json`) и доступны только по вашему токену (вкладка «Данные»).

## Проверки

В папке `tests/` лежат автоматические проверки: остатки, пределы КТ и ККТ, аннулирование, слияние данных при синхронизации, основные экраны на компьютере и телефоне. GitHub запускает их при каждом пулреквесте (вкладка Actions, «Проверки»).

Запуск у себя: `npm install`, затем `npx playwright install chromium` и `npm test`.

## Устройство кода

Сборки нет: страница подключает файлы из папки `js/` по порядку, каждый опирается на предыдущие, последним идёт `js/main.js`. В начале каждого файла написано, за что он отвечает. Новый файл нужно добавить и в `index.html`, и в список `SCRIPTS` в `sw.js` (проверка `tests/files.spec.js` следит, чтобы списки совпадали).
