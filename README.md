# haccp-app

Веб-приложение HACCP-прослеживаемости варенья и джемов: приёмка сырья → производство → реализация, прослеживание по коду с банки и по лоту сырья.

Открыть: https://philhovhannisyan-sudo.github.io/haccp-app/

Здесь только код приложения. Данные хранятся в приватном репозитории `Claude-projects` (`data/haccp.json`) и доступны только по вашему токену (вкладка «Данные»).
